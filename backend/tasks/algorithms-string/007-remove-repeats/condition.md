# Написать функцию, которая будет удалять дубликаты букв в словах

Написать функцию, которая будет удалять дубликаты букв в словах

    removeRepeats("Кккоооот Бааарссиккк зззапрыыгнннул   наааа зааабоооррррр") => "Кот барсик запрыгнул на забор"

Правила:
- первый символ результата сохраняется как есть, остальные приводятся к нижнему регистру;
- сравнение соседних символов регистронезависимое;
- повторяющиеся подряд пробелы сворачиваются в один.
